There are 4 things to use your AoPs account to fetch.

1. User ID
    - Integer
    - Open devtools console, find AoPS.session.user_id
2. session ID
    - AoPS.session.id
3. SID
    - Application -> Storage -> Cookies \_uetsid
4. Headers - Network panel - Find an ajax request to AoPS, copy the headers
